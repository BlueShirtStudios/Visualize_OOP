# Visualize OOP

## 📌 Overview
Object Orientation can feel like a black box at first, but using this tool within ***your codebase*** will make understanding it no problem. This program reads your source code and builds UML-like diagrams to display relationships between objects. Combined with a pattern analyzer, you have the perfect resource to understand object behavior.

---

## ✨ Key Features
* **🌳 Class Hierarchy Generator**
  * Renders complex hierarchy trees across interfaces and abstract classes.
  * Highlights access modifiers and members of the class within its diagram.

* **🎨 Design Pattern Detector**
  * Analyzes codebase to determine the design patterns used in the project.
  * From the global structure to smaller patterns between clasees

* **⚡ Explore Seamlessly**
  * Presentable as UML or node diagrams using Microsoft Graph Library.
  * Drag and drop nodes as you wish to explore or edit the diagram.
  * Has a print option to create a picture of the diagram that you can use.
