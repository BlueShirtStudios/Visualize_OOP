# Visualize OOP

## 📌 Overview
Object Orientation can feel like a black box at first, but using this tool within ***your codebase*** will make understanding it no problem. This program reads your source code and builds UML-like diagrams to display relationships between objects. Combined with a memory tracker, you have the perfect resource to understand object behavior.

---

## ✨ Key Features
* **🌳 Class Hierarchy Generator**
  * Renders complex hierarchy trees across interfaces and abstract classes.
  * Highlights access modifiers and members of the class within its diagram.

* **📦 Memory Allocator**
  * Simulates runtime behavior of objects and how it affects the heap.
  * Visual representation of the memory lifecycle for objects.

* **🎨 Design Pattern Detector**
  * Analyzes codebase to determine the design patterns used in the project.

* **⚡ Display Anywhere**
  * Presentable as UML or node diagrams using 3rd-party graphic components.
  * Viewable or analyzable directly in the terminal for fast access.
  * Formatted to different file types based on your needs.
