# Visualize OOP

##📌 Overview
Object Orientation can feel like a black box at first, but using this tool within ***your codebase*** you will make understanding it with no problem. This program will 
read your source code and build a UML like diagrams to display relationships between the objects within the codebase. Combine a graphical representation with a memory tracker
you have the perfect resource to understand objects.

---

##✨ Key Features
* **🌳 Class Hierarchy Generator**
  ** Renders complex hierarcy trees acrosss interfaces and abstract classes.
  ** Highlisghts access modifiers and members of the class with its diagram.

* **📦Memory Allocator**
  ** Simulate run time behavior of the object and how its effects the heap.
  ** Visual representation of memory lifecycle for the objects.

* **🎨Design Pattern Detector**
  ** Analyze codebase to determine the patterns used in the project.
  
* **⚡Display Anywhere**
  ** It can be presented as a UML or Node diagram using 3rd party graphic components.
  ** For fast access it can be viewed or analyzed in the terminal.
  ** Or it can be formatted to differant file types based on your needs
